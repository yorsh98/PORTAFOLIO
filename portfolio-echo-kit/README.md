# portfolio-echo-kit

Kit para construir un portafolio animado estilo "ECHO" guiado por la skill `portfolio-guide`.

- `index.html` · `css/styles.css` · `js/main.js` — demo funcional (HTML/CSS/JS sin dependencias)
- `js/content.js` — todo el contenido (texto e imágenes)
- `brief.md` — ficha por sección (la skill la completa con preguntas)
- `scrum.md` — plan por sprints
- `skill/SKILL.md` — la skill (instalar como `portfolio-guide`)
- `assets/img/` — tus imágenes (retrato, capturas)

Probar: abre `index.html` en el navegador (o `python3 -m http.server`) y baja con el scroll.
Tipografías: Google Fonts (Manrope, JetBrains Mono); sin conexión usa la fuente del sistema.
